Finance Behaviour System

ML-powered behavioral finance analytics platform for transaction analysis, spending pattern detection, anomaly detection, and automated financial insights.


Project Goal

This project aims to analyze financial transaction data and identify behavioral spending patterns using feature engineering, clustering, anomaly detection, trend analytics, and explainable insights.

The system is designed as a scalable analytics pipeline rather than a simple finance dashboard.
